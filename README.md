# ChatGPT Speed Booster

Браузерное расширение, которое убирает тормоза в длинных чатах ChatGPT. Скрывает сообщения за пределами экрана, уменьшая нагрузку на браузер.

## Установка

Расширение устанавливается вручную, без магазина расширений.

### Chrome

1. Откройте в адресной строке `chrome://extensions`
2. В правом верхнем углу страницы включите переключатель **Режим разработчика** (Developer mode)
3. Слева вверху появится кнопка **Загрузить распакованное расширение** (Load unpacked) — нажмите на неё
4. В открывшемся окне выберите папку с файлами расширения (ту, в которой лежит `manifest.json`)
5. Расширение появится в списке и в панели инструментов браузера

### Edge

1. Откройте в адресной строке `edge://extensions`
2. В левой панели включите переключатель **Режим разработчика** (Developer mode)
3. Нажмите кнопку **Загрузить распакованную** (Load unpacked)
4. Выберите папку с файлами расширения
5. Расширение появится в списке и в панели инструментов

### После установки

Откройте любой чат в ChatGPT. Расширение включится автоматически и начнёт скрывать сообщения, которые находятся за пределами видимой области. В popup расширения (клик по иконке) можно посмотреть сколько сообщений скрыто и изменить настройки.

## Настройки

- **Enable Speed Booster** — включить или выключить расширение
- **Messages Buffer** — сколько сообщений оставлять выше и ниже видимой области. Меньше значение — быстрее работает, но при быстрой прокрутке может быть заметна подгрузка. Рекомендуется 5-15.

## Обновление

Если вы изменили файлы расширения, зайдите в `chrome://extensions` (или `edge://extensions`), найдите карточку расширения и нажмите кнопку обновления. После этого перезагрузите страницу ChatGPT.

## Удаление

На странице `chrome://extensions` (или `edge://extensions`) нажмите **Удалить** на карточке расширения.
